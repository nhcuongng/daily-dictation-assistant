- (decision) AD-1: Tech Stack - Vanilla JavaScript without a build step (or simple Vite) for MVP. Solo dev needs zero friction, and UI injection (slider, buttons) is too simple to warrant React/Vue overhead.
- (decision) AD-2: Core Logic Location - All core logic (UI injection, Hotkeys, Audio control) lives in Content Scripts running specifically on dailydictation.com. Background Service Worker (Manifest V3) is deferred until Phase 3 (if needed for cross-tab tracking).
- (decision) AD-3: UI Injection Pattern - Use DOM element creation (document.createElement) appended adjacent to stable anchor IDs defined in PRD. Avoid Shadow DOM for simplicity unless CSS conflicts arise.
- (decision) AD-4: State and Storage - chrome.storage.local acts as the single source of truth for user preferences (speed setting) and future tracking data. Read on load, write on change.
- (event) spine finalized
